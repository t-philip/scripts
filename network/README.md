## EVE-NG — Network Emulator

[EVE-NG](https://www.eve-ng.net) (Emulated Virtual Environment - Next Generation) is a network emulation platform used to design, test, and learn network topologies. The Community Edition is free.

The guide in `eve-ng/installation` covers:
- Downloading and installing VMware Workstation Player (free)
- Downloading and importing the EVE-NG OVF image
- Recommended VM settings (RAM, disk, processor, network adapter)
- Default credentials and first login
- Common errors and their fixes
